# Nuvo – Fintech Landing Page (HTML & CSS practice)

A sample fintech landing page with no JavaScript: HTML + CSS only.

- `index.html` / `style.css` – the finished page (CSS is numbered in 16 commented sections)
- `assets/` – logo, icons, avatars, card images (all PNG) and `palette.png`
- `design-reference/landing-desktop-full.png` – full-page screenshot (1440px wide)

## Palette
Navy ink `#0a1630` · Blue `#3b5bfd` · Mint `#12d8a0` · Violet `#7c4dff` · Sky tint `#eef2ff` · Mint tint `#e1faf2` · Body text `#51607f` · Border `#e3e8f3` · Page bg `#f6f8fc`

## Type
Inter (fallback system-ui). H1 clamp(40px, 5.4vw, 66px), section titles clamp(30px, 3.6vw, 44px), body 17px/1.6, tight letter-spacing on headings (−0.025em).

## Techniques to study
sticky blurred nav (`backdrop-filter`) · gradient text (`background-clip:text`) · CSS-only phone mockup · radial-gradient hero glow · `auto-fit/minmax` grids · pricing card with raised "popular" plan · FAQ with `<details>` (no JS) · responsive breakpoints at 960px and 560px.

All names, figures and artwork are made-up sample content.

## fintech website
- a modern and responsive fintech website design to give users a clean, intuitive, and user-friendly digital financial experience.
- built with html and css, focusing on neat layout and responsive design
- used grid and media query for the cards and (`transform: rotate(6deg);`) to rotate the phone
- working on development
